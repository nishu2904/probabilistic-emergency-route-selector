# Probabilistic Emergency Route Selector

A probability-based emergency route selection system that evaluates uncertain travel time, traffic conditions, and road risks to select the route with the highest probability of timely arrival.

## Objective

The system compares multiple possible emergency routes using probability and statistical concepts rather than simply selecting the shortest route.

## Probability Concepts

- Random Variables
- Probability Distributions
- Conditional Probability
- Bayes' Theorem
- Expected Value
- Variance
- Monte Carlo Simulation
- Expected Risk
